# SLIDING_WINDOW
This repository contains implementations and examples of the Sliding Window technique, a powerful method used to solve array and string problems efficiently. The sliding window approach is widely used in problems involving subarrays, substrings, and continuous sequences.

Features
Solve common sliding window problems
Efficient O(n) solutions for many array and string challenges
Includes both fixed-size and variable-size window techniques

Problem Examples
Examples of problems covered in this repository:
Maximum sum subarray of size K
Longest substring without repeating characters
Minimum size subarray sum
Count of subarrays with sum K
